# 자리 뽑기

교실 좌석을 참가자 번호에 무작위로 배정하는 웹 애플리케이션입니다.

## 배포 주소

<https://jari-bbob.vercel.app/>

## 주요 기능

- 행과 열을 지정해 좌석 배열을 구성할 수 있습니다.
- 참가자 수를 기준으로 1번부터 참가자 번호를 자동으로 생성합니다.
- 좌석은 최대 20행 x 20열, 참가자는 최대 500명까지 설정할 수 있습니다.
- 제외할 참가자 번호를 쉼표로 입력할 수 있습니다.
- 추첨 전에 좌석을 선택해 제외 좌석으로 지정할 수 있습니다.
- 앞자리 우선 기능을 켜고 원하는 참가자 번호를 지정할 수 있습니다.
- 추첨 전에 좌석 배열과 앞자리 우선 좌석을 미리 확인할 수 있습니다.
- 3초 카운트다운 후 좌석을 배정합니다.
- 배정 결과에서 참가자 번호, 행과 열 위치, 앞자리 우선 배정 여부를 확인할 수 있습니다.
- 추첨이 끝난 뒤 좌석을 드래그해 두 참가자의 위치를 서로 바꿀 수 있습니다.
- 추첨 결과는 현재 브라우저에 최근 10개까지 자동 저장됩니다.
- 저장된 결과를 다시 불러오거나 개별적으로 삭제할 수 있습니다.
- 추첨 결과를 16:9 비율의 고해상도 PNG 이미지(3200 x 1800)로 저장할 수 있습니다.
- 결과를 클립보드에 복사하거나 인쇄할 수 있습니다.
- 일반 좌석표와 3D 교실 장면을 전환할 수 있습니다.
- 3D 모드에서 카메라를 회전·확대하고 좌석을 드래그해 참가자 위치를 교환할 수 있습니다.
- 입력 범위를 벗어난 번호나 배정할 수 없는 조건을 안내합니다.
- 추첨 결과가 나온 뒤 다시 뽑을 수 있습니다.

## 사용 방법

1. 행과 열을 입력합니다.
2. 참가자 수를 입력합니다.
3. 필요한 경우 제외 번호를 쉼표로 입력합니다.
4. 추첨 전 좌석표에서 제외할 좌석을 누릅니다. 선택한 좌석에는 `X`가 표시됩니다.
5. 앞자리 우선 배정이 필요하면 기능을 켜고 번호를 입력합니다.
6. `추첨하기`를 누릅니다.
7. 카운트다운이 끝나면 좌석 배정 결과를 확인합니다.
8. 필요한 경우 결과 좌석을 드래그해 두 참가자의 자리를 교환합니다.
9. 결과 화면의 `이미지 저장`, `복사`, `인쇄` 버튼으로 결과를 활용합니다.
10. 필요하면 결과 상단의 `일반`과 `3D` 버튼으로 좌석 표시 방식을 전환합니다.

제외 번호와 앞자리 우선 번호는 참가자 수 범위 안의 정수만 입력해야 합니다. 같은 번호를 여러 번 입력하면 한 번만 처리됩니다. 좌석 제외 설정과 추첨 기록은 현재 브라우저에만 저장되며 다른 기기와 동기화되지 않습니다.

## 로컬 실행

프로젝트 루트에서 의존성을 설치합니다.

```bash
pnpm install
```

개발 서버를 실행합니다.

```bash
pnpm --filter @workspace/seat-draw dev
```

브라우저에서 `http://localhost:5173`을 엽니다.

## 빌드 및 검사

전체 타입 검사와 자리 뽑기 앱 빌드를 실행합니다.

```bash
pnpm run build
```

자리 뽑기 앱의 빌드 결과는 다음 경로에 생성됩니다.

```text
artifacts/seat-draw/dist/public
```

## Vercel 배포 설정

GitHub 저장소를 Vercel에 연결하면 `main` 브랜치에 push할 때 자동으로 배포할 수 있습니다.

- Install command: `pnpm install --frozen-lockfile`
- Build command: `pnpm run build`
- Output directory: `artifacts/seat-draw/dist/public`
- Deploy command: 설정하지 않음

이 프로젝트는 별도의 API 키나 런타임 환경 변수를 사용하지 않습니다.
